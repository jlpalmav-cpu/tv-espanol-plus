# PalmaVision 2.5.3 — Compilación Android

Rama independiente de la versión estable. El código fuente completo viaja comprimido como partes en `.palmavision-source/` y el flujo `build-palmavision-v253.yml` lo reconstruye, verifica SHA-256 y ejecuta Gradle para generar un APK. La aplicación permanece en horizontal fijo y es exclusivamente para móvil táctil. El APK no se debe considerar aprobado hasta que CI y las pruebas de instalación terminen.
